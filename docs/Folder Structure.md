# Folder Structure

- `app/Domains`: domain-driven scaffolding with consistent subfolders across platform domains.
- `app/Support`: cross-cutting platform enums and navigation metadata.
- `app/Http/Controllers/Platform`: thin controllers for dashboard and scaffold pages.
- `config`: modular platform configuration by concern.
- `database/migrations`: foundation schema only.
- `resources/js`: Inertia React UI, premium admin shell, and placeholder pages.
- `docker`: PHP, nginx, and workspace container assets.
- `docs`: rationale and future integration guidance.
